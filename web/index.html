 Reloading a model

            
A model is read from disk the first time it is used and released from memory automatically after 2 minutes without activity. To force a fresh load, unload it first — the next request reads it again.

            

              

                From the panel
                
                  Unload all
                  in this tab, or the bin icon next to a loaded model to unload just that one.

                Slot device
                Changing a slot's device makes the next request load the model into a matching slot instead.
              

              

                While in use
                A model with active requests is never unloaded. If every slot is busy the API returns 503 — retry in a moment.
